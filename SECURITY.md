# Security Policy

## Reporting a vulnerability

Please do not report security issues in public GitHub issues, discussions, or pull requests.

Report them privately through GitHub instead:

1. Go to the [Security tab](https://github.com/gudlab/gudcal-core/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected version or commit, and the steps to reproduce it.

Only the maintainers can see the report. We will reply in the advisory thread, keep you updated while we fix it, and credit you in the advisory if you want.

## Supported versions

We fix security issues on the latest `main` branch. If you self-host GudCal, please stay up to date with `main`.
